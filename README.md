# TS Port (Vue 3 + TypeScript)

Порт фронтенда с JS/EJS на Vue 3 Composition API и strict TypeScript.

## Команды

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run typecheck`

## Примечания

- Легаси-источники в `src/` не изменялись.
- Новый код расположен только в `ts-port/`.
- Для корректного отображения изображений можно перенести статику в `ts-port/public/images`.
